# 다솔 창작 아카데미 개인용 앱

v19 커리큘럼을 기반으로 만든 개인용 PWA입니다.

기능:
- 오늘 날짜를 자동으로 인식해 해당 날짜의 미션 표시
- 날짜 선택으로 다른 날 미션 확인
- 672개 미션
- 완료 체크 저장(localStorage)
- 주차/전체 진행률 표시
- 홈 화면에 앱처럼 설치 가능
- 인터넷 없이도 처음 한 번 로드한 뒤 사용하도록 서비스 워커 포함

## 아이폰에서 사용하는 방법

이 폴더를 HTTPS로 제공되는 웹 주소에 올린 뒤 Safari에서 접속하세요.
Safari의 공유 버튼 → '홈 화면에 추가'를 누르면 앱처럼 사용할 수 있습니다.

주의:
- 이 파일만 아이폰 파일 앱에서 열어서는 PWA 설치 기능이 제대로 동작하지 않을 수 있습니다.
- PWA 설치에는 HTTPS 주소가 필요합니다.
- 완료 체크는 해당 아이폰/브라우저의 저장공간에 저장됩니다.
